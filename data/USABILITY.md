# Dataset usability audit

The audit establishes structural suitability for retrospective experiments, not that the full research protocol is implemented or scientifically validated. Run `python3 scripts/download_data.py`, `python3 scripts/download_optional_data.py`, and `python3 scripts/audit_data.py` to repeat integrity and structural checks. All five datasets have standard amino-acid sequences, finite continuous scores, unique sequences and enough rows for the planned budget. The four extracted FLIP CSV files match their gzip archives byte-for-byte; their decompressed contents also match FLIP2 Zenodo archive v3. Original labels remain visible in the raw files: a query interface must hide them from optimizers.

| Dataset | Rows | Structural assessment and remaining work |
| --- | ---: | --- |
| Amylase | 3,706 | Suitable for development using the existing position-shift split (1,782 train / 1,924 test). Verify score direction and obtain a verified wild-type reference for mutation constraints. |
| IRED | 8,586 | Suitable for number-shift tests using the existing split (4,408 train / 4,178 test). The file exactly matches the archived benchmark split, confirming the download is intact; the reason the site quotes 17,143 variants remains unresolved. Verify target direction and wild type. |
| Hydro | 24,935 | Suitable for fitness-shift tests with care: the file contains three sequence lengths (57, 63, 65), representing different proteins. Establish wild-type identity and decide separate pools or a justified cross-protein protocol; Hamming distance across different lengths is undefined. Verify target direction. |
| GB1 | 8,733 | Suitable as an additional fitness-shift benchmark (5,089 train / 3,644 test). The full 265-residue sequences include a larger construct; use the documented inferred reference and four variable positions. Blank validation fields are not missing sequences; handle them as non-validation after verifying the source convention. |
| ProteinGym GFP | 51,714 | Suitable as an additional fluorescence assay after adapting `mutated_sequence` and `DMS_score` to the common schema. Higher score is better. There is no existing seed/test split in this file: define and record a label-safe split. Using the provided reference sequence, 35,584 variants are within four substitutions; all mutation counts agree with sequence differences. |

FLIP/FLIP2 split membership can define the initial seed pool, but care is needed for fitness-based splits: the split was constructed using fitness labels, so this is a retrospective benchmark assumption and must be disclosed. Use only initial labeled data for fitting, calibration, and decisions; do not expose hidden scores, global fitness statistics, or held-out evaluation labels. Enforce budgets and ensure enough eligible candidates remain after each dataset's mutation limits. GFP may require substantial embedding time. Validation flags, model calibration, per-protein normalization, oracle/query logic and candidate search remain implementation work.
